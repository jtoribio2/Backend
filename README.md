# Cómo visualizar la página web

## 1. Iniciar XAMPP

Para visualizar la página web, es necesario tener XAMPP instalado y encendido.

1. Abre el panel de control de XAMPP.
2. Inicia el servicio Apache.
3. Comprueba que Apache esté funcionando correctamente.

## 2. Acceder al proyecto

Abre el navegador y entra en la siguiente dirección:

http://localhost/

Desde localhost, accede a la carpeta del proyecto, que se encuentra en la siguiente ruta:

`C:\xampp\htdocs\practiques\bakend\nf1\00Continguts\ProjBack\`

También puedes acceder directamente mediante esta URL:

http://localhost/practiques/bakend/nf1/00Continguts/ProjBack/

Al entrar, se abrirá el archivo index del proyecto.

## 3. Navegar por la página web

Una vez dentro de la página principal:

- **Registro:** pulsa el botón "Registro" para acceder a la página de registro de usuarios.
- **Iniciar sesión:** pulsa el botón "Iniciar sesión" para acceder al contenido de la página principal.

## Importante

XAMPP debe estar encendido y el servicio Apache debe estar iniciado para que la página web funcione correctamente.
